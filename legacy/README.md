# Contrato operativo protegido

`billing-original.htm` conserva la versión funcional del cliente de facturación recibida antes del rediseño. Se utiliza **solo su script**, extraído en tiempo de compilación. No se publica el HTML, el CSS ni las imágenes anteriores.

No edites este archivo para cambiar el diseño. Usa `src/pages/facturacion.astro` y `src/styles/billing.css`. Las pruebas comprueban que el script compilado sea idéntico y que los campos y validaciones de ambos formularios se conserven.
